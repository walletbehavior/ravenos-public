# RavenOS Public Documentation

RavenOS is a market intelligence platform built around structure, pressure, replay, participation, rotation, and market context.

This public repository contains the customer-facing site, public-safe data contracts, Worker routes, and documentation. It does not include private Raven runtime data, private participant identifiers, trading logic, execution systems, wallet lists, token targets, or proprietary model weights.

## Public-Safe Boundary

Public RavenOS documentation and artifacts may describe aggregate concepts such as:

- Participation breadth
- Pressure alignment
- Replay similarity
- Reward persistence
- Survival
- Confidence
- Sample depth
- Chain
- Cap band
- Structure
- Outcome

They must not expose private participants, private wallet data, private runtime artifacts, execution internals, private token targets, or proprietary model internals.

## Methodology Principle

RavenOS should show its work without exposing private systems.

Every major public read should answer:

1. What is happening?
2. Why does Raven believe it?
3. How fresh is the read?
4. How much evidence supports it?
5. What would weaken the read?

RavenOS provides software, analytics, research, and market context. It does not provide investment advice, brokerage, custody, investment management, trade execution, buy recommendations, or sell recommendations.
